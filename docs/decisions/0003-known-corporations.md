# 0003: Known Cyberpunk corporations

Date: 2026-10-10
Status: Accepted

Combine corporation names indexed for Cyberpunk 2020 and 2077 into one flavor and one local TypeScript list. Deduplicate by source page. Preserve each entry's source link for later review; do not require a connection at runtime.

The Known corporations category picks an existing setting name directly, making the flavor data easy to test. It appears only for setting flavors. The original Corporations category still composes new names and can use setting corporations as parent companies. Do not invent employee counts for directly selected known corporations.

The imported indexes are a broad working list, not a verified exhaustive canon catalogue. See ../data-sources.md for coverage and limitations.
