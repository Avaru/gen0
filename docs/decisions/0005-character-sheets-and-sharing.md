# 0005: Character sheets and sharing

Full editable sheets use dedicated routes and Pinia stores. Share basic sheet components, URL compression, and synchronization while keeping each sheet's fields and rules separate. Sheets reuse existing generators and approved profiles, and remain editable aids rather than rules validators. Detailed fields, source mappings, and class rules live in the [character data model](../character-data-model.md).

## Saving and sharing

Save full-sheet edits locally and share them through a versioned, compressed `char` query parameter. Update the URL automatically through Vue Router after each Vue update, without a debounce, replacing history without overwriting newer edits. Copy the address-bar URL to save or share a character.

Valid URL data takes priority over local storage; without a character query, use the locally saved sheet. Validate versions and size bounds. Invalid links retain existing edits and show an error. Edits still save locally, and other generator and About URLs omit sheet data. Links contain the full character, require no backend, and can be read by anyone who has them. Long descriptions make longer links.

## CBR+PNK runner sheet

`/chars/cbrpnk` always uses Cyberpunk/Generic for its theme and generation, with no flavor query on its navigation link. The sheet is saved under `gen0.character` and starts blank when no usable saved sheet exists. Its catalogue lives in `src/data/characters/`.

The Runner card has editable Alias and Name & description fields, with Generate and Reset beside its heading. Generate opens the archetype picker; choosing one fills the runner fields from the existing Runners category using Generic and the chosen archetype. It also fills Approaches, Skills, and expertise from the matching CBR+PNK profile. A source skill value of 3 becomes two rating points plus one matching expertise.

After applying the profile, Approaches and Skills each independently have a 20% chance to move one point from a rating of 1 or 2 to another field below 2, keeping each total. Applying an archetype also picks one linked augmentation using the existing generator's flavor name, optional descriptor, purpose text when present, and manufacturer as one editable line. It fills the first slot, clears the other two slots and all augmentation Glitched marks, or leaves all slots blank when no links exist. Harm, Stress, and Approach Glitched marks remain manual. The random augmentation pool has [archetype suitability links](../character-data-model.md#random-augmentation-archetype-links) without restricting standalone generation.

Resist/Armor follows Stress. Its only control, Special Armor, turns the card yellow when checked and is saved with the sheet. Load/Gear tracks selected gear against Light [3], Medium [5], or Heavy [7], turns yellow at the limit and red above it, and saves its selections.

### Printing

Keep CBR+PNK printing separate from screen layout and preserve component state across responsive layouts. On the default-scheme sheet (Generic/Shadowrun), use the browser's Print command to print or Save as PDF: A4 portrait, 100% scale, browser headers/footers disabled. The print layout removes the app shell and actions, keeps the desktop card order in two columns, and shows selections without background graphics. Filled custom expertise fields use the selected expertise style and appear in print only when filled. Long descriptions wrap and may extend the sheet to further pages; claim print fit only after browser/PDF verification.

## Never Midnight student sheet

The feature-gated `/chars/never-midnight` route has its own Pinia store and local storage key, `gen0.character.never-midnight`, and shares compressed URL saving and restoration with CBR+PNK. It provides a student file, Blood/Thought/Voice Means, six disciplines, and editable spell and sacrifice lists.

Summon opens the nationality picker and fills the name and combined age/looks/occupation description. Small reroll buttons refresh either field using the chosen nationality. Summon also replaces the spell list with three spells from the Spells generator; each spell has a reroll button that replaces only its text. Name and description rerolls preserve spells.

Summon applies three occupation discipline bonuses and one matching subdomain, and randomly adds three Means points in a +2/+1 split. Description rerolls replace occupation bonuses and the subdomain while preserving Means; name rerolls preserve ratings. Keepsake and sacrifices stay manual. Spells are plain text without levels. Means, disciplines, and sacrifice ratings run from 1 to 3 and start at 1; spells and sacrifices start empty.

## Mothership character sheets

Each generic name can open a mini character sheet below the generator controls, showing class, stats, saves, and randomly assigned starting skills. Name lists generate only the name, pronouns (equally from he/him, she/her, and they/them), class, appearance, trinket, and patch. Opening a card rolls the remaining fields for that class; reopening the same result rolls a fresh character. Starting gear is chosen equally from the ten supplied loadouts for that class and shown as an Equipment list. Shared item definitions and loadout references, including quantities and ammunition, live in `src/data/characters/mothership-gear.ts`. Mini resources are read-only: current Stress is uniform from 2–19, Health shows only its normally rolled maximum, and current Wounds is 0/1/2 with 80%/15%/5% chances. Minimum Stress and maximum Wounds are hidden. Credits range from 50–100,000 with a logarithmic distribution favoring smaller balances (median about 2,236). Trauma Response is hidden in mini sheets. Full-sheet generation keeps its normal starting resources and credits. Mini sheets are temporary and do not write character data to the URL or local storage.

Shared skill definitions and class starting-skill rules live in `src/data/characters/mothership-skills.ts` and `mothership-rules.ts`. Every prerequisite list means any one is sufficient. Selection and prerequisite checks live in Mothership patterns; the mini sheet displays the assigned skills. Only the open mini card holds its full character data.

The full sheet lives at `/chars/mothership`, with two columns on desktop and stacked cards on mobile. It starts blank when no usable saved sheet exists and saves under `gen0.character.mothership`, using the shared compressed URL saving and restoration described above. A document icon beside each name's sheet arrow carries that result into the full page, preserving an already open mini character for that row. Existing `/mothership/generic?char=…` links open the full page with the saved character. Generate fills the sheet directly from the existing Characters generator without opening a picker. Generate, Reset, and Print sit on the right of the app header above the commit hash and stripe decoration, wrapping below the title on smaller screens. Reset follows the CBR+PNK confirmation: “really?” clears the saved sheet and URL to a blank sheet, while “nah.” cancels. Reset is hidden for a blank sheet. Re-roll buttons refresh name, appearance text, portrait, stats, saves, maximum health, skills, equipment (including trinket and patch), and credits. Pronouns and class remain manually editable. Each re-roll preserves unrelated edits. Manual class selection changes only the label and trauma response. Skills and equipment re-rolls replace their corresponding manual text overrides; equipment also resets its armor override. Maximum-health re-rolls clamp current Health to the new maximum. The layout follows the supplied character-profile reference, using the app's fonts, cards, and fields. Personal Details includes Player Name below High Score; there is no separate profile card. Its editable values share the Class field typography. The name re-roll sits inside its field on desktop and alongside it on tablets and phones. Other re-rolls sit at the card or field edge without expanding headings. Display textareas have subtle dashed writing lines, and Notes has a larger initial writing area. Appearance shows the selected portrait, or editable text after the image is removed. Player name, character name, pronouns, class, High Score, stats, saves, current/maximum resources, skills, equipment, armor points, credits, trinket/patch, conditions, and notes are editable. Pronouns use a plain text field. Trinket and patch are ordinary lines in the editable Equipment list on the full sheet and mini card. High Score starts blank. Fresh full-sheet generation leaves Current Health, Wounds, and Stress blank; opening an existing mini character carries its rolled Stress and Wounds into those fields. Entered current values are kept in the URL; clearing an input makes it blank again. Stress shows its editable Minimum instead of a maximum. Editing class changes its label and trauma response without rerolling other fields. Status Report puts the read-only, non-resizable trauma response without a heading above an initially empty Conditions field. The right column ends with an initially empty Notes card. Weapons sections and skill training are omitted. Existing weapon items remain in the generated equipment text.

Newly rolled characters automatically receive a random portrait from the fixed set of 122 supplied JPGs. Portraits fill the Appearance area and crop as needed. Reroll at the bottom left always selects a different portrait; Remove image at the bottom right restores the unchanged appearance text. The Image icon can then pick a portrait again. The portrait number is saved in the character URL and the selected image appears in print. Restoring a character link preserves its portrait choice, including no portrait if it was removed or absent in an older link.

Full-sheet edits update its saved character and URL, including manual skill/equipment text and optional detail fields. Old version-1 links without these additions still load; absent pronouns remain blank. Returning to the sheet through navigation preserves edits.

The full sheet's Print button opens the browser print dialog. Printing includes only its sheet content, with field values instead of editing controls. The print page is A5 portrait with 7 mm margins (134 × 196 mm of usable space), leaving room for two sheets on A4 using the print dialog's two-pages-per-sheet option. The sheet fills one A5 page, with Conditions and Notes aligned at the bottom. Skills and Equipment keep eight and ten printed lines respectively; overflowing text stays within the allocated fields rather than adding pages.

The arrow rolls a fresh mini card. The document action opens the current mini character for that row without rerolling, or rolls it first when needed. Full-sheet edits are independent of the temporary name list.
