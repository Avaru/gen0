# 0001: Local generators and data

Bundle the data with a Vue/TypeScript/Vite app so generation needs no backend or remote data connection. Keep itemcards.com unchanged; exclude its fantasy/DSA generators.

- Settings own their categories, defaults, flavors, theme, caption, and optional character-sheet navigation in `src/generator/settingRegistry.ts`. Cyberpunk is the initial and default setting; it preserves all existing content. Never Midnight is registered only when `SETTING_NEVER_MIDNIGHT=true`, reuses existing German/Russian/Polish personal-name data with uniformly selected ages from 18 through 65, and defaults to German. Each result also gets one job from its own translated DDR catalogue and supplied additions, preserving repeated entries; see [job sources](../never-midnight-job-sources.md). Appearance uses an everyday selection copied from the existing hair styles, shares face shapes, and uses only the supplied Never Midnight hair colors; bald heads omit color. Clothing appears on 25% of results and combines the supplied condition and style lists with the shared general clothing wording, without a garment. Cybernetic features and eye descriptions are omitted. Its composition lives in `src/patterns/never-midnight/`. A setting is separate from flavor tags; sharing data or composition is explicit.
- Within Cyberpunk, Generic is the default. Shadowrun and combined Cyberpunk 2020/2077 are whole flavors, with setting details enabled together.
- Editable lists live in `src/data/`; preserve human-made entries, source order, and duplicate weights. AI-authored additions require explicit consent. Source links and reuse notices remain available for review.
- Ordinary tags select pools; flavor tags restrict availability. Include/exclude options override defaults, with exclusions winning. Pass options explicitly through all nested calls.
- `flavorNames` and `flavorShortNames` change spelling without changing availability. Shared concepts retain IDs; ordinary rows need none. Technomancer is Shadowrun-only; Netrunner/Decker shares one role. Human species labels appear only with Shadowrun.
- Keep setting categories in `src/generator/definitions/`; shared `categories.ts` selects the active setting. Keep options in `options.ts`, composition in `src/patterns/cyberpunk/`, and loading/filtering in `src/builders/load.ts`. Shared datasets use purpose names rather than a setting prefix; `people/` contains shared name, job, and species composition. The CBR+PNK catalogue contains active sheet definitions and profiles; unused import configuration and augmentation tables are removed. Functions return results synchronously; name-only helpers avoid generating unused descriptions.
- `Bits` owns independent selection pools; filtering creates another pool and `take()` removes one entry. `NamePools` indexes and caches personal-name parts without caching results or consuming random draws. Retain up to eight normalized flavor/tag combinations; each person gets independent picks.
- Empty required pools report errors. Eligibility checks skip traditions missing any part their rules may request, including optional parts.
- Split personal-name files into individual production chunks and other data into `generator-data`, for separate caching. All lists still load at startup.
- Serve `dist/` over HTTP with the app entry point as the route fallback. Vercel runs `npm run check` before deployment. No service worker is included; online fonts have local fallbacks.

Inherited lists are not fully audited for spelling or canon accuracy. Preserve explicitly retained unused Shadowrun pools and `src/data/fashion.ts`; Birka and Fashion Items have no active flavor, theme, or generator.
