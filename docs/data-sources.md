# Corporation data sources

Inspected: 2026-10-10

- [Cyberpunk 2020 corporation index](https://cyberpunk.fandom.com/wiki/Category:Cyberpunk_2020_Corporations): 382 corporation pages across both index pages.
- [Cyberpunk 2077 corporation index](https://cyberpunk.fandom.com/wiki/Category:Cyberpunk_2077_Corporations): 130 corporation pages.

The combined list contains 431 distinct source pages, deduplicated by URL. Only names and source links were collected; article descriptions were not copied. Navigation, category links, thumbnails, and user sandbox pages were excluded. Each TypeScript entry retains its individual page URL.

This is the union of these community-maintained indexes, not a guarantee of every corporation in every sourcebook or game. The indexes may contain historical, real-world, or noncanonical companies. Both eras deliberately share one flavor, so the list is not filtered by in-world date.

Shadowrun data was migrated from itemcards.com's local lists. Its original source content has not undergone a full editorial or canon review.
